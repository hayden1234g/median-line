# Median Line

A Sleeper fantasy football dashboard. Enter any Sleeper username to see every league for that account on one page: official, head-to-head, vs-median and all-play records, live scores against each league's weekly median, and a week-by-week chart.

Live: https://hayden1234g.github.io/median-line/ (add `?user=yourname` to link straight to your leagues)

It's one static `index.html` that calls the public [Sleeper API](https://docs.sleeper.com/) from the browser. No backend, no login.
